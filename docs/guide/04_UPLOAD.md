# 04 UPLOAD — 제목·설명·태그·업로드·성과

## 1. 제목 패턴

`[장면/상황] + [장르] + [Playlist/플리]` — 장면이 앞.

- JP: `【Playlist】深夜の首都高、ひとりで流すシティポップ | City Pop Night Drive`
- JP: `雨の日のカフェで聴くチルポップ 1時間 ☕ 作業用BGM`
- KR: `[Playlist] 퇴근길 한강, 창문 열고 듣는 팝 🌆`
- KR: `일요일 오전 10시, 카페에서 작업할 때 듣는 플리`

규칙: 60자 안팎, 콘셉트에 없는 단어(유명 가수명 등) 금지. 실제 가수 이름을 낚시로 쓰지 않는다.

## 2. 설명란 구조 (`description.txt` 자동 초안)

1. 장면 한두 문장 (콘셉트)
2. **큐레이션 노트** — 이 순서로 묶은 이유 2~3줄
3. 타임스탬프 챕터
4. 크레디트·AI 표기 (`本チャンネルの楽曲はAIツールを用いて制作しています` / `이 채널의 음원은 AI 도구를 활용해 제작했습니다`)
5. 해시태그 3개

## 3. 업로드 체크리스트

- [ ] 변경·합성 콘텐츠 공개 = **예** (AI 음원 포함 시)
- [ ] 챕터가 설명란에 있고 00:00부터 시작
- [ ] 썸네일 = 영상 비주얼 + 짧은 장면 문구 (설계안은 우리가, 제작은 사용자)
- [ ] 재생목록(시리즈) 추가, 최종 화면에 다음 플리
- [ ] 업로드 후 24시간 내 **저작권 탭(Content ID)** 확인
- [ ] `tracks.csv`의 `last_used` 갱신

## 4. 성과 기록 `docs/performance-log.md`

7일·28일 시점: 노출수, CTR, 평균 시청 시간, 평균 시청률, 구독 전환, 트래픽 소스(탐색/추천/검색).
플리는 **평균 시청 시간(분)** 과 **추천 트래픽 비율**이 핵심. 3편 이상 쌓이면 장면 유형별로 비교한다.
